# Agent instructions

The CFD workflow for this repo — how to turn `cases/scenarios/<name>.yaml`
into a validated OpenFOAM case with a narrated `REPORT.md` — is in
[`CLAUDE.md`](CLAUDE.md). Read it before setting up or running a case, and
follow it exactly; it applies to every agent, not just Claude.

Kilo users: the `cfd`, `cfd-orchestrator` and `cfd-local` agents in
`kilo.jsonc` already carry these instructions (see `.kilo/prompts/`).
