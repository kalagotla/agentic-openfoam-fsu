# NACA 0012 airfoil

2-D extruded NACA 0012 at Re_c = 1e6, α = 10°, M = 0.15. Scenario: [`cases/scenarios/naca-0012.yaml`](../../scenarios/naca-0012.yaml).

## Geometry

`geometry/naca0012.stl` is generated by [`geometry/generate_naca0012.py`](geometry/generate_naca0012.py) (stdlib only). Re-run with different arguments to change resolution, chord length, or trailing-edge closure.

## Reference

`reference/xfoil_polar.json` — Cl and Cd vs α from XFOIL v6.99 (Ncrit=9). Provenance and tolerance guidance: [`reference/README.md`](reference/README.md).

## Runtime

~10–15 min total (mesh + solve) on a 4-core laptop at the scenario's default refinement levels.
